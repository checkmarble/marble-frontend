# Marble Frontend

Bun monorepo (`packages/*`) on TanStack Start — SSR React 19 via Vite + Nitro, with the React Compiler intentionally disabled — using TanStack Router, Query and Form, Radix UI, Tailwind 4, Zod, and Biome.

## Commands

Package scripts run through the workspace filter:

```bash
bun run -F app-builder dev          # dev server
bun run -F app-builder type-check   # tsc --noEmit (every package except tests)
bun run -F '*' type-check           # all packages, as CI does
bun run -F app-builder build
bun run -F app-builder unit-tests
bun run test:all                    # unit-tests in app-builder, backoffice, ui-design-system (the only packages with one)
bun run format:write                # Biome format only
bunx biome check --write <files>    # format + organize imports + safe fixes (CI runs biome ci .)
```

## Packages

- `app-builder` — the main app; the layout below describes it
- `backoffice` — separate back-office app
- `ui-design-system` — shared components, imported as `from 'ui-design-system'`
- `marble-api` — API client generated from OpenAPI specs
- `ui-icons`, `@marble/shared` (dir `packages/shared`), `typescript-utils`, `tailwind-preset` — support packages
- `tests` — Playwright e2e suite (`bun run -F tests test`; starts the backend with testcontainers, needs Docker)

## app-builder layout

`src/` holds `routes/` (file-based: `_app/` pages, `ressources/` endpoints), `server-fns/`
(createServerFn handlers called from React Query), `components/`, `queries/` (one file per
query), `repositories/`, `services/`, `models/` (types with adapters), `middlewares/`
(`authMiddleware`, `servicesMiddleware`, `caseDetailMiddleware`), `schemas/` (Zod),
`contexts/`, `hooks/`, `utils/`, `locales/` (`en`, `fr`, `ar`).

Generated output — edit the source and regenerate rather than the output:

- `src/routeTree.gen.ts` in app-builder and backoffice — regenerated by `dev` and `build`
- `packages/marble-api/src/generated/*` — `bun run -F marble-api generate-api`, from
  `packages/marble-api/openapis/*.yaml` (the core spec is split across `openapis/marblecore-api/`)
- `packages/ui-icons/src/generated/*` — `bun run -F ui-icons generate-icons`, from `packages/ui-icons/svgs/`

## Working agreements

- Work on a feature branch; on `main`/`master` a hook blocks Edit/Write tool calls (it can't
  see shell writes, so don't write files from Bash there either).
- Finish with a clean `type-check`. A stop hook Biome-formats changed and new `.ts`/`.tsx`
  files and type-checks every package you changed, and sends you back on failure.
- Reach for non-destructive git: `push --force`, `reset --hard`, `clean -f` and
  `checkout .` are blocked.

## Troubleshooting

Stale build output: `rm -rf packages/app-builder/.output && bun run -F app-builder build`

## Agent configuration

Path-scoped conventions live in `.claude/rules/`, which `.cursor/rules/*.mdc` wraps for
Cursor. Domain guidance and workflow skills (e.g. `dependabot`) are in `.claude/skills/`; subagents in
`.claude/agents/`. Codex reads this file via the `AGENTS.md` symlink and discovers the
same skills through `.agents/skills`. Codex hooks are registered in `.codex/hooks.json`
and run the scripts in `.claude/hooks/`. For how the pieces fit and where to put a new
one, read `.claude/claude-developer-guide.md`.
